## [1.0.0] - 2026-10-13

### Added
- **Core Engine & Architecture:**
  - Двумерный буфер терминала с ячейками `Cell` (символ `rune`, цвета FG/BG, ANSI-стили текста).
  - Изолированный рендеринг через `Canvas` и `SubCanvas` с автоматическим клиппингом и относительными координатами.
  - Кроссплатформенная поддержка терминала (Windows conhost VT100 / Linux / macOS) с поддержкой UTF-8.
  - Асинхронный event-loop (`App.Run`) с очередью событий (`EventQ`), каналом фоновых действий (`actions`) и тиками (`OnTick`).
  - Поддержка динамического ресайза окна терминала (`TerminalResizeEvent`).
  - Централизованный менеджер фокуса (`FocusManager`) с переключением по Tab / Shift+Tab.
  - Реестр глобальных клавиатурных сочетаний (shortcuts).
  - Полноценная поддержка мыши по протоколу SGR (клики, drag, колесо прокрутки) и хит-тестинг компонентов.
- **Styling System & Flex Layout:**
  - Tailwind-подобный синтаксис классов стилей (`fg:*`, `bg:*`, `border-*`, `p-*`, `text-*`, `truncate`, `clip`).
  - Псевдосостояния стилизации: `normal`, `focus`, `active`, `disabled`, `selected`, `hover`.
  - Flexbox-контейнер (`Box`) с поддержкой направлений (`flex-row`, `flex-col`) и коэффициента роста (`flex-1`).
- **Widgets:**
  - `Label` — отображение однострочного текста с рамками и выравниванием.
  - `Button` — интерактивная кнопка с обработкой нажатий и визуальными состояниями.
  - `Input` — однострочное поле ввода с фильтрами символов и курсором.
  - `InputArea` — многострочный текстовый редактор с поддержкой навигации и редактирования.
  - `TextArea` — многострочный текстовый блок с поддержкой режима пишущей машинки (typewriter).
  - `ListView` — список элементов с выбором и прокруткой.
  - `Box` — универсальный контейнер компонентов с поддержкой отступов (padding) и Flex-лейаута.
  - `ProgressBar` — прогресс-бар с анимацией, кастомными рунами заполнения, таймером и форматированием.
  - `Image` — виджет отрисовки изображений в символьную графику терминала.
- **Examples:**
  - `examples/login_form` — форма авторизации.
  - `examples/music_player` — интерактивный консольный плеер.
  - `examples/style_gallery` — витрина всех стилей, flex-компонентов и ProgressBar.
- **CI/CD:**
  - GitHub Actions матричный пайплайн кроссплатформенной сборки и тестирования (Ubuntu + Windows).
