# cli-graphics

Легковесный компонентный графический движок для создания интерактивных интерфейсов в терминале (TUI) на языке **Go**.

---

## Ключевые особенности
* **Canvas API & SubCanvas:** единый теневой буфер и легковесные холсты с изолированными координатами и автоматическим отсечением.
* **Дифференциальный рендеринг:** сравнение кадров и вывод в терминал исключительно изменившихся ячеек.
* **Компонентная модель:** готовые виджеты (`Box`, `Button`, `Input`, `Image`, `ListView`) с поддержкой древовидной вложенности.
* **Focus Manager:** встроенное переключение фокуса по клавише `Tab` и адресная доставка событий клавиатуры активному элементу.
* **Потокобезопасная асинхронность:** планирование изменений UI из фоновых горутин через очередь действий `app.Post(func())`.
* **Безопасность терминала:** автоматический перевод терминала в `Raw Mode` и гарантированное восстановление параметров при выходе или `panic`.

## Быстрый старт

```go
package main

import (
	"cli-graphics/engine"
	"cli-graphics/widgets"
	"fmt"
	"image"
	"net/http"

	_ "image/jpeg"
	_ "image/png"
)

func main() {
	// Создание корневого контейнера
	rootScreen := widgets.NewBox(0, 0, 80, 24)
	
	// Создание и компоновка виджетов
	btnImage := widgets.NewButton(10, 20, "Загрузить фото", nil)
	picture := widgets.NewImage(40, 10, 40, 20, nil)

	rootScreen.AddChild(btnImage)
	rootScreen.AddChild(picture)
	rootScreen.SetFocus(true)

	app := engine.NewApp(rootScreen)

	// Асинхронная загрузка и безопасное обновление интерфейса
	btnImage.OnClick = func() {
		go func() {
			resp, err := http.Get("https://avatars.yandex.net/get-music-content/16334817/73d15c0c.a.16218390-2/400x400")
			if err != nil || resp.StatusCode != http.StatusOK {
				return
			}
			defer resp.Body.Close()

			img, _, err := image.Decode(resp.Body)
			if err != nil {
				return
			}

			// Передача действия в поток рендеринга
			app.Post(func() {
				picture.SetImage(img)
			})
		}()
	}

	if err := app.Run(); err != nil {
		fmt.Printf("Error: %v\n", err)
	}
}
```

## Архитектура и структура проекта

* **`engine/`** — ядро графического движка:
  * `app.go` — главный цикл приложения (Event Loop, обработка тиков, восстановление терминала).
  * `buffer.go` — матрица ячеек терминала и алгоритм дифференциального сброса кадра.
  * `canvas.go` — абстракция рисования примитивов со смещением координат и отсечением.
  * `focusManager.go` / `focusable.go` — управление фокусом ввода и циклической навигацией по Tab.
  * `component.go` / `container.go` — базовые интерфейсы и дерево визуальных компонентов.
* **`widgets/`** — библиотека пользовательских компонентов (`Box`, `Button`, `Input`, `Image`, `ListView`).
* **`utils/`** — низкоуровневые утилиты парсинга клавиш и получения размеров терминала.
