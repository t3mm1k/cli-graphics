# Настройка среды разработки и конфигурация IDE

В данном документе описаны параметры инженерного окружения, выбранный технологический стек и конфигурация среды разработки (IDE), установленные для обеспечения качества кода проекта `cli-graphics`.

## 1. Базовый технологический стек

* **Язык программирования:** Go (Golang)
  * *Версия:* 1.27.1 (в соответствии со спецификацией в `go.mod`).
  * *Инструментарий экосистемы:* Стандартные средства компилятора (`go test`, `go fmt`, `go vet`).
* **Внешние зависимости:**
  * `github.com/stretchr/testify/assert` (v1.12.1) — фреймворк утверждений (assertions) для модульного тестирования.
  * `golang.org/x/term` (v0.46.0) — кроссплатформенное управление терминалом и перевод в Raw Mode.

## 2. Интегрированная среда разработки (IDE)

* **Основная IDE:** Visual Studio Code (VS Code) версии 1.94+
* **Ключевые установленные плагины:**
  * **Go (от Google):** Обеспечивает глубокую интеграцию с языковым сервером Go (`gopls`), предоставляя статический анализ в реальном времени, автодополнение и проверку типов.
  * **Easy Go Lint:** Интегрирует запуск анализатора `golangci-lint` прямо в интерфейс редактора для мгновенного подсвечивания ошибок и архитектурных недочетов.
  * **EditorConfig for VS Code:** Автоматически применяет правила форматирования кода независимо от операционной системы разработчика.

## 3. Правила форматирования и рабочее пространство

Стиль кода и структура файлов унифицированы во всем репозитории с помощью конфигурационных файлов, размещенных строго в корне проекта, и комбинации двух форматтеров кода.

### Форматирование кода и документации (go fmt и Prettier)
В проекте реализовано четкое разделение обязанностей между инструментами автоматического форматирования для обеспечения сквозного качества всех типов файлов:
* **go fmt:** Используется в качестве основного встроенного форматтера для всех исходных файлов на языке Go (`.go`). Он автоматически выравнивает структуры, расставляет отступы и гарантирует соответствие кодовой базы официальному стандарту языка.
* **Prettier:** Применяется в качестве специализированного форматтера для файлов разметки, документации (`.md`) и конфигурационных файлов (`.yaml`, `.json`). Это гарантирует, что все генерируемые отчеты по лабораторным работам, README-файлы и настройки линтеров имеют строго единообразную структуру, правильные отступы списков и переносы строк.

### Настройки EditorConfig (`.editorconfig`)
Рабочее пространство автоматически синхронизировано по следующим стандартам для предотвращения конфликтов между Windows и Unix-системами:
* **Символ конца строки:** LF (`\n`) для предотвращения ошибок компиляции символьных буферов из-за Windows-символов возврата каретки (`\r\n`).
* **Кодировка текста:** UTF-8 (критически важно для корректного отображения кириллицы и ANSI-символов рамок, таких как `┌`, `─`, `╭`).
* **Отступы в файлах Go:** Строго на основе табуляции (Tab) с шириной отображения в 4 пробела, что соответствует официальному стандарту языка (Go Code Review Comments).
* **Отступы в markdown/yaml:** На основе пробелов (indent_size = 2/4) в соответствии с правилами валидации форматтера Prettier.

### Глобальные горячие клавиши
В IDE настроены следующие сочетания клавиш:
* `Shift + Alt + F` — автоматическое форматирование текущего открытого файла с помощью соответствующего форматтера (`go fmt` для кода или `Prettier` для документов).
