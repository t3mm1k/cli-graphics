# Функциональные требования

### Подсистема управления терминалом и жизненным циклом
* **FR-01 (Raw Mode):** Система должна автоматически переводить терминал в сырой режим(*raw mode*).
* **FR-02 (Восстановление терминала):** Система должна гарантированно восстанавливать исходное состояние терминала и курсора при штатном завершении работы и при возникновении `panic`.
* **FR-03 (Адаптивный размер):** Система должна отслеживать изменение геометрии окна терминала и генерировать событие изменения размера для пересчета разметки.
* **FR-04 (Журналирование):** Система должна поддерживать запись отладочных сообщений и ошибок в файл логов без засорения вывода терминала.

### Подсистема буферизации и графического вывода
* **FR-05 (Двойная буферизация):** Система должна хранить внутренний буфер ячеек (символ, цвет текста, цвет фона, стили атрибутов).
* **FR-06 (Дифференциальный рендеринг):** При отрисовке кадра система должна сравнивать текущий буфер с предыдущим и отправлять в stdout только изменившиеся ячейки.
* **FR-07 (Отрисовка примитивов):** Canvas API должен предоставлять методы отрисовки прямоугольников, рамок (одинарных, двойных), заливки областей и вывода строк.
* **FR-08 (Отсечение отрисовки):** Система должна блокировать вывод символов дочернего компонента за пределами границ родительского Canvas (`SubCanvas`).

### Подсистема обработки ввода и событий
* **FR-09 (Парсинг клавиш):** Система должна в отдельной горутине перехватывать ввод с клавиатуры, распознавать спецклавиши (стрелки, Tab, Enter, Backspace) и генерировать нормализованные события.
* **FR-10 (Кастомные комбинации):** Система должна поддерживать задание пользовательских комбинаций нажатых клавиш, с событиями привязывающимися к ним.
* **FR-11 (События мыши):** Система должна поддерживать обработку кликов мыши и скролла колесиком для виджетов.
* **FR-12 (Таймер обновления):** Система должна поддерживать настраиваемый такт обновления экрана (TickRate) для анимаций и периодических проверок.

### Подсистема управления фокусом
* **FR-13 (Навигация по Tab):** Система должна автоматически переключать фокус ввода между интерактивными компонентами по нажатию клавиши `Tab` (и `Shift+Tab` в обратную сторону).
* **FR-14 (Индикация фокуса):** Сфокусированный элемент должен изменять свое визуальное состояние (цвет рамки, инверсия или видимый курсор).
* **FR-15 (Модальные окна и Focus Trap):** При открытии модальных окон система должна изолировать фокус исключительно внутри диалога, блокируя ввод для фоновых компонентов.

### Подсистема виджетов и компонентной модели
* **FR-16 (Иерархия компонентов):** Система должна обеспечивать древовидную вложенность компонентов (контейнер может содержать произвольных дочерних компонент).
* **FR-17 (Контейнеры):** Различные типы контейнеров с координатным/относительным/автоматическим позиционированием.
* **FR-18 (Кнопка):** Виджет кнопки должен поддерживать отображение надписи, визуальный отклик на фокус/нажатие и вызов зарегистрированного обработчика `OnClick`.
* **FR-19 (Поле ввода):** Виджет ввода должен поддерживать ввод текста, перемещение курсора, удаление символов, фильтрацию ввода и маскирование (режим пароля).
* **FR-20 (Список):** Виджет списка должен поддерживать прокрутку элементов и выбор строки с помощью клавиш со стрелками.
* **FR-21 (Прогресс Бар):** Виджет должен отображать текущее состояние выполнения фоновой задачи.
* **FR-22 (Изображение):** Виджет для вывода графических файлов в ANSI псевдографике.
* **FR-23 (Таблицы):** Виджет таблицы должен отображать данные в формате таблиц, с возможностью фокуса и выбора конкретной ячейки. Также в ячейках могут располагаться другие компоненты.
* **FR-24 (Вкладки):** Виджет вкладок для переключения между несколькими экранами без перезапуска приложения.
* **FR-25 (Многострочный ввод):** Виджет для ввода и редактирования многострочного текста (TextArea).
* **FR-26 (Уведомления/Модальные окна):** Всплывающие информационные сообщения с выбором действий.
